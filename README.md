## 📘 Project Description
This project is part of the **CS213 – Programming Assignment 1** at Cairo University, Faculty of Computers and Artificial Intelligence.  
It is an **Image Processing Program** written in **C++**, which allows users to load, edit, and save images using a variety of filters.

The project demonstrates knowledge in:
- File handling  
- Image pixel manipulation  
- Loops and nested loops  
- Conditional statements  
- Modular programming with multiple filters

## 🧠 How It Works
1. The program starts by asking the user to input the image file name.  
2. The user selects from a **menu of 18 options**, each corresponding to a filter or operation.  
3. After applying filters, the user can **save** the modified image under a new name or overwrite the existing one.  
4. The user can exit the program safely after saving the work.
